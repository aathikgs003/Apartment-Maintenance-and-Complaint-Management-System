# 🏢 Apartment Maintenance System - Frontend

The client-side application for the Apartment Maintenance & Complaint Management System. Built with **React 18**, **Tailwind CSS**, and **Vite**.

## 🚀 Key Features

- **Resident Portal**: Raise complaints with image uploads, track real-time status, and rate completed work.
- **Maintenance Staff Portal**: View assigned tasks, update status (In Progress/Completed), and upload work proof.
- **Admin Dashboard**: Comprehensive analytics, user management, complaint assignment, and delay monitoring.
- **Real-time Notifications**: Global notification system with unread counts and status alerts.
- **Mobile Responsive**: Optimized for use on mobile, tablet, and desktop devices.

## 🛠️ Tech Stack

- **Framework**: React 18 (Functional Components & Hooks)
- **Routing**: React Router v6
- **State Management**: React Context API
- **Styling**: Tailwind CSS
- **API Client**: Axios (with Interceptors)
- **Charts**: Recharts
- **Icons**: Heroicons (v2)
- **Date Formatting**: date-fns
- **Toasts**: react-hot-toast
